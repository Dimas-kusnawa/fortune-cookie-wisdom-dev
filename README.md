A program that writes one original fortune-cookie line for a software developer to `/output/entry.txt`: "The bug you cannot reproduce has already reproduced — in production, at 3 a.m., on your holiday." (96 characters, inside the 120-character cap.) It reads like a real fortune, says something true about a developer's day, and turns on the double meaning of "reproduce": the bug you cannot make happen has already made itself happen without you.

## Run it

```sh
python3 main.py
```
